# LinkedIn Agent Skill pack (li-*)

The eleven `li-*` Claude Code skills that LinkedIn Studio uses to write, humanize and score posts.

Originally created by Jake Schincariol (opusjake.ai) and shared by Avi Grondin at
https://github.com/avi691/linkedin-agent-skill under the MIT License (see `LICENSE` in this folder).
This copy may include local changes.

`../setup.sh` copies these folders into `~/.claude/skills/`, where Claude Code picks them up.
